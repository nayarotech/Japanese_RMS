# infrastructure/storage

S3-compatible object storage behind a small interface (`object-storage.ts`): `put`, `get`, `delete`, `publicUrl`.
Drivers: `s3` (staging/production), `local` (single-host development), `memory` (tests, with fault injection).

- Keys are generated by callers on the server and must match a strict pattern (no `..`, no leading slash); browsers
  never choose keys or see credentials.
- `publicUrl` returns `STORAGE_PUBLIC_BASE_URL/<key>` when configured, otherwise the API media route path.
